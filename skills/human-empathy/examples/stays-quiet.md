# Example: when it stays quiet, and when it adds two lines

Activation is earned. Three requests in the same repositories as the other
examples.

## A typo in the book: quiet

> Fix the typo "recieve" in chapter 2.

The reply is the fix: one word in `chapters/02-python-refresher.md`. No ⚡ line,
no book review, no mention of chapter 3. A typo is a typo. The book's real
problems are not this request's business, however serious they are.

## A button label: quiet

> Change "Submit" on the sign-up form to "Create account".

The reply is the change. The label is better, and nothing about the request
asks how the flow feels. The lost-input defect in the same file stays
unmentioned: an unrequested review of a whole flow on a one-word change is
exactly what gets a skill uninstalled.

## A build request that names its people: CONSULT

> Add a "Just me" option to company size; most of our sign-ups are solo
> freelancers.

The request names who it is for, and one experience risk changes what gets
built:

```
⚡ Human Empathy — company size for solo sign-ups

Adding "Just me" fixes the missing answer. The field is still required before
a solo freelancer can send a first invoice; if sales does not need it at sign-up,
making it optional (or asking later) removes the question entirely. Building the
option as asked.
```

Then the work. Two lines, a recommendation, and the request done as asked.
