# Example: a large feature that does not name the pipeline

**Request:** *"Build a full subscription billing system with Stripe: plans,
trials, cancellation, webhooks and invoices."*

This is a large, risky feature: money, an external provider, webhooks and
personal data. It is still not an invitation. The request does not name the
pipeline.

What happens is the ordinary per-request selection. Standards Compass, API
Contract Guard, Dependency Guard and ProofBuild engage because this request
earns them, each at its own depth. No menu appears. Nothing asks for a
sequence, and no ledger is printed at the end.

The pipeline would engage only on:

- `/skills-pipeline build subscription billing …`
- *"Run subscription billing through the skills pipeline."*

The same holds for *"use Impact Map before this"*, which engages Impact Map
alone, and for *"set up a CI pipeline"*, which is a different kind of pipeline.

Why it stays out: an agent that turns every big request into a ten-stage
ceremony gets uninstalled. The pipeline is useful because someone asked for it.
